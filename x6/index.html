X6

Personal keyword research tool for Windows

What X6 is

X6 is a desktop application that runs only on its owner's own Windows computer (it serves its interface on 127.0.0.1 and is not a web service). It helps one person research advertising keywords for websites they are studying.

X6 is a private, non-commercial tool used by its developer. It is not sold, offered to the public, or used to manage anyone else's Google Ads accounts.

How X6 uses the Google Ads API

After the user signs in with their own Google account and authorizes X6, the app calls the Google Ads API on the user's own Google Ads account, read-only, to look up keyword planning data:

  • Keyword ideas and historical metrics (KeywordPlanIdeaService): average monthly searches, low / high top-of-page bid, average CPC, competition, and monthly search volumes for the last 12 months.
  • The results are shown to the same user inside the app on their computer.

X6 does not create, change, or pause campaigns, ads, budgets, billing, users, or any other account settings, and it does not access any account the user does not own or manage.

Data and security

  • OAuth tokens are stored only on the user's computer, encrypted with Windows DPAPI. They are never sent anywhere except to Google.
  • X6 does not have a server and does not collect, sell, or share any data.
  • The user can disconnect at any time in X6 (Settings → Google Ads → Clear) or by removing access at myaccount.google.com/permissions.

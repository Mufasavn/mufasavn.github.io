Privacy Policy

X6 desktop application · Last updated: November 11, 2026

1. Who we are

X6 is a personal desktop application for Windows developed by Mufasavn. It runs only on the user's own computer and has no backend server. This policy explains what data X6 accesses and how it is handled.

2. Google user data X6 accesses

When the user chooses to connect Google Ads, X6 asks for the Google OAuth scope https://www.googleapis.com/auth/adwords, which Google requires for the Google Ads API. X6 uses it only to read keyword planning metrics for the user's own Google Ads account (keyword ideas, average monthly searches, top-of-page bid ranges, average CPC, competition, monthly search volumes).

X6 does not read campaign performance, ads, billing, or personal profile data, and it never makes changes to the Google Ads account.

3. How the data is used

Keyword metrics are displayed to the same user inside X6 and may be cached on the user's computer for up to 30 days so the same lookup does not call the API again. The data is not used for advertising, profiling, or training any model, and it is not used for any purpose other than showing it to the user.

4. Storage and security

  • All data stays on the user's computer in the user's local application data folder.
  • OAuth refresh tokens and client secrets are encrypted with Windows DPAPI, so only the same Windows user account can read them.
  • X6 communicates only with Google services over HTTPS. It has no server of its own and no analytics or tracking.

5. Sharing

X6 does not sell, rent, transfer, or share Google user data or any other data with anyone. No human other than the user reads the data.

6. Google API Services User Data Policy

X6's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Retention and deletion

  • Cached keyword data expires after 30 days and can be cleared at any time.
  • To disconnect, use X6 → Settings → Google Ads → Clear, which deletes the stored tokens, and/or revoke access at myaccount.google.com/permissions.
  • Uninstalling X6 and deleting its local data folder removes all data.

8. Changes

If this policy changes, the updated version will be published on this page with a new date.
